# Engineering invariant
- TypeScript strict, testable data model, semantic landmarks, functional navigation and meaningful alt text; avoid unnecessary deps.
- Never leak secrets, embed tokens, scrape private pages, execute arbitrary downloaded scripts or silently publish to third parties.
- Avoid large animations on reduced-motion preferences. Keyboard focus and pointer accessibility must work.
- Preserve existing files and commit checkpoints instead of deleting/reinitializing a project indiscriminately.
- No acceptance based only on compilation: actual interaction + visual browser review are mandatory.
