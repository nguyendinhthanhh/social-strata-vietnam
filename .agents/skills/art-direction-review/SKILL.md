# Steps
1. Produce two clearly different visual directions then choose an intentional one.
2. Define typography supporting Vietnamese, token contrast checks and editorial modular layouts.
3. Assess actual screenshots if provided; call out crop, visual balance, text legibility, hierarchy and story pacing.
4. Require mobile-specific art direction, not card stacking.
5. Iterate, recording image evidence paths and exact issues.
