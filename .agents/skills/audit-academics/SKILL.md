# Steps
1. Read all three lesson PPTX and extracted per-slide text; note inaccessible figures.
2. Enumerate factual claims from seed and selected documents.
3. Create `docs/SOURCE_LEDGER.md` with stable IDs `S-001` etc, author, date, URL/file+slide, claim and source type.
4. Record findings in `docs/ACADEMIC_AUDIT.md`; label unsupported claims.
5. Allow content freeze only when every material claim is verified or attributed and source IDs resolve.
